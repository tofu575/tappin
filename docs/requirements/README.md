# TapPin

## 概要

- ボタンをタップして現在地を記録
- 記録した座標はアプリ内で閲覧可
- 後からGoogleMapを開き、付近にどんなものがあったかを見返すことができる

## ターゲット

- 運転中など、手が離せない状況で気になるものを見つけた時にメモできる
- 既存のアプリではいくつかの手順を踏んでからブックマークをしないといけないため、そこが差別化点

## 機能一覧

- アプリのホームにある大きなボタンで現在地を記録
- 右上のメニューから、過去の記録地点をリストアップ
  - リストのボタンから、GoogleMapの地点、ストリートビューを開く
  - 不要な場合はゴミ箱ボタンから削除
