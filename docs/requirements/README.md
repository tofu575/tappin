# Tappin

## 概要

- 気になった瞬間の場所をワンタップで記録
- 未確認の記録をあとから順番に振り返る
- 外部地図で場所を調べ、メモと確認済み状態を残せる

Tappinは、移動中に見つけた場所を最小限の操作で取りこぼさず、
安全な状況で記録するためのアプリである。

## ターゲット

- 散歩、旅行、公共交通機関、同乗中などに見つけた場所を記録できる
- 既存のアプリではいくつかの手順を踏んでからブックマークをしないといけないため、そこが差別化点

## 安全に関するプロダクト方針

- 自動車の運転中や自転車の運転中など、端末操作が危険な状況での利用を推奨しない
- Quick Modeは運転支援機能ではなく、画面全体をタップして素早く現在地を記録する機能として扱う
- UI、App Store掲載素材、Webサイトで、「運転中でも使える」と訴求しない
- 車のアイコンは同乗中の移動を表す用途で使用できるが、運転者が端末を操作する表現と組み合わせない
- 自転車は運転者自身の操作を強く連想させるため、Quick ModeのUIや訴求にアイコンを使わない
- 運転者は操作しないよう、Quick Modeの案内で明示する

## 機能一覧

- アプリのホームにある大きなボタンで現在地を記録
- Home右端のインデックスタブから履歴を開く
  - 未確認と確認済みを明示的に分ける
  - カード全体から詳細を開き、Google Mapsやストリートビューで場所を確認する
  - 詳細でメモを編集し、確認済みにする
- Quick Modeでは画面全体のタップで現在地を記録する
  - 安全な状況でのみ操作するよう案内する
  - セッション中は徒歩、車（同乗中）、バスの移動キャラクターを表示する
  - 約1.5秒の長押しで終了する
